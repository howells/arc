# Installing Arc for Codex

The recommended install is the native Codex plugin. It puts Arc in Codex's isolated
plugin cache, so Arc's skills never collide with other skills you have installed. A
clone-and-symlink installer remains available as a fallback.

## Prerequisites

- Codex (CLI, IDE, or app) recent enough to include `codex plugin` (Codex CLI 0.117+)
- Git

## Native Plugin Install (Recommended)

```bash
codex plugin marketplace add howells/arc
codex plugin add arc@howells
```

`marketplace add` registers Arc's marketplace; `plugin add` installs the self-contained
Arc plugin (`plugins/arc/` in the repo) into `~/.codex/plugins/cache/howells/arc/<version>`.
It bundles Arc's skills, agents, references, disciplines, templates, scripts, and rules,
so full-runtime workflows have their supporting material.

Manage and update:

```bash
codex plugin list                  # what's available / installed
codex plugin marketplace upgrade   # refresh the marketplace snapshot, then `plugin add` again
codex plugin remove arc            # uninstall
```

Invoke workflows with `$<skill-name>` (`$audit`, `$ideate`, `$implement`, `$review`,
`$refactor`, `$testing`, `$launch`, `$commit`, `$vision`). Restart Codex if skills do
not appear immediately.

## Fallback: Clone-and-Symlink Installer

For older Codex builds without `codex plugin`, or if you prefer skills surfaced from your
home skills directory:

```bash
curl -fsSL https://raw.githubusercontent.com/howells/arc/main/.codex/install.sh | bash -s -- --auto-update --interval-hours 6
```

This clones Arc to `~/.codex/arc` and symlinks its skills into `~/.agents/skills` (Codex's
user skills directory), with a `~/.codex/skills` mirror for older builds. Because these
skills share your flat skills namespace, they can collide with same-named skills from
other sources — prefer the native plugin when you can.

A prompts-only channel such as `npx skills add howells/arc` copies `SKILL.md` files only
and omits Arc's bundled material, so full-runtime workflows will not have their supporting
files.

## Verify

```bash
codex plugin list   # native install: arc@howells -> installed, enabled
```

For the fallback installer:

```bash
ls -la ~/.agents/skills/{audit,ideate,implement}
readlink ~/.agents/skills/audit   # -> ~/.codex/arc/.agents/skills/audit
```

## Uninstalling

Native plugin:

```bash
codex plugin remove arc
codex plugin marketplace remove howells
```

Fallback installer:

```bash
find ~/.agents/skills -maxdepth 1 -type l -lname "$HOME/.codex/arc/.agents/skills/*" -delete
find ~/.codex/skills  -maxdepth 1 -type l -lname "$HOME/.codex/arc/.agents/skills/*" -delete
rm -rf ~/.codex/arc
```

## Maintainer Note

`plugins/arc/` and `.agents/plugins/marketplace.json` are generated by
`pnpm build:codex` (run after a version bump) and committed so the native install works
from GitHub. Do not edit `plugins/arc/` by hand — change the root sources and rebuild.
